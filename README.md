# Student-Performance-Analytics
📊 Student Performance Analytics

Este projeto analisa o desempenho acadêmico de estudantes a partir de um conjunto de dados que inclui notas em diversas disciplinas e informações como antecedentes familiares, nível de preparação para testes e outras variáveis socioeducacionais.
O objetivo é identificar padrões, correlações e fatores que mais influenciam o rendimento dos alunos.

📁 Sobre o conjunto de dados

O dataset contém:

Notas dos alunos em diferentes matérias

Nível de educação dos pais

Tipo de preparação para testes

Ambiente familiar

Outras características que podem influenciar o desempenho escolar

O foco deste projeto é entender como fatores externos e socioeconômicos influenciam o desempenho acadêmico.

🧠 Objetivos do projeto

Explorar e limpar os dados

Identificar relações entre variáveis

Analisar a influência dos antecedentes familiares e preparação para testes

Gerar visualizações que facilitem a interpretação dos resultados

Apoiar decisões e reflexões sobre performance educacional

🛠️ Tecnologias e Bibliotecas Utilizadas

Python

Pandas

NumPy

Matplotlib / Seaborn

Google Colab

📈 Principais Análises

Distribuição das notas

Comparação de desempenho entre diferentes grupos

Impacto da educação dos pais nas notas

Relação entre preparação para testes e performance

Identificação de padrões significativos

📊 Resultados

Foram identificados insights importantes sobre como o ambiente familiar, preparo e variáveis externas impactam no rendimento escolar.
As visualizações mostram tendências claras e ajudam a interpretar de forma simples e objetiva os fatores que mais influenciam as notas.

▶️ Como executar

Faça o download ou clone este repositório

Abra o notebook no Google Colab ou localmente

Instale as dependências, se necessário

Execute as células na ordem
